
# Python Calculator

## About the Project
This is a simple calculator project built using Python.
It performs basic arithmetic operations.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Handles division by zero

## Technologies Used
- Python

## How to Run
1. Install Python.
2. Open the project folder in the terminal.
3. Run the command:

   python calculator.py
